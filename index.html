Software Error Consultation: ZeroDivisionError in Attendance Calculation

Systematic root-cause analysis, defect reproduction, and remediation recommendations for the attendance analytics engine.

Module Affected analytics/attendance.py
Defect Classification Unhandled Arithmetic Exception
Runtime Environment Python 3.10+ / Backend Calculation Service
Resolution Status Fix Proposed & Verified

Diagnostic Summary

Error Message: ZeroDivisionError: division by zero
Underlying Cause: Total classes or student count is zero (e.g. empty roster or inaugural class session prior to enrollment). The operation divides by total without validating whether total > 0.
Suggested Fix: Implement boundary check: verify if total is greater than zero before performing division. Return 0.0% if total equals zero.
Sample Buggy Implementation (Python)
Throws ZeroDivisionError 
# BUGGY: Fails when total == 0
def attendance_percentage(present, total):
    return (present / total) * 100

# Execution Trace:
# attendance_percentage(0, 0)
# Traceback (most recent call last):
#   File "attendance.py", line 2, in attendance_percentage
#     return (present / total) * 100
# ZeroDivisionError: division by zero
✗ Unsafe for production when class sessions or roster count is 0.
Recommended Patched Implementation (Python)
Production Ready 
# FIXED: Guard against zero division gracefully
def attendance_percentage(present, total):
    if total <= 0:
        return 0.0
    return round((present / total) * 100, 2)

# Verified Test Cases:
# attendance_percentage(0, 0)   => 0.0%  (Safe)
# attendance_percentage(18, 20) => 90.0% (Accurate)
✓ Guard condition prevents runtime crash and returns neutral 0.0%.
